# Liuli Society Website

A Vite + React + Tailwind website package for GitHub upload and deployment.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Upload this project to GitHub, then connect the repository to Vercel or Netlify.

### Vercel
- Import the GitHub repository
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

### Netlify
- Build command: `npm run build`
- Publish directory: `dist`

## Note
The contact form is currently visual only and does not send email yet.
